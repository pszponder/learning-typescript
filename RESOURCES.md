# TypeScript Resources

## Knowledge

- [TypeScript Handbook: Everyday Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html)
  Primary reference for function annotations, inference, aliases, and literal unions. First lesson: Functions and Literal Types.
- [TypeScript Handbook: The Basics](https://www.typescriptlang.org/docs/handbook/2/basic-types.html)
  Primary reference for static checking and erased types. Use to separate compiler guarantees from runtime behavior.
- [TypeScript Handbook: Narrowing](https://www.typescriptlang.org/docs/handbook/2/narrowing.html)
  Primary reference for refining unions with runtime checks and modeling distinct states. Use in upcoming input-validation and state lessons.
