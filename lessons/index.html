The Adventurers’ Guild campaign

Build small pieces of a future RPG backend: dungeon rules, inventory, quests, and saved state. Each lesson now has a Guild quest with explicit rules, acceptance cases, and a hidden hint. Choose the quest as your main exercise; use the older drills for extra practice. No D&D rules knowledge is required.

How to practice: each lesson has an additional worked example with a hidden walkthrough and an optional practice ladder. Predict, modify one rule, then implement a related problem using explicit cases. Finish the short main exercise first; use the extra work in a second session.

For a cross-collection checklist, use the core operations reference. Each collection lesson now includes operation-specific examples and three short practice sessions.

After the single-level operations and loops, try nested collection practice: game grids, team/player records, and room membership.
