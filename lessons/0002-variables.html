Choose a binding: const, let, var

Your win: Track a game score and explain which names may be reassigned.

A binding is a name referring to a value. Use const when the binding stays fixed and let when you reassign it. Both have block scope: braces delimit their scope. var is function-scoped (or global outside a function), so an if block does not contain it. Prefer const by default and let for deliberate reassignment.

const target = 7;
let attempts = 0;
attempts += 1;

if (true) {
  var oldScore = 10;
  let roundScore = 20;
}
console.log(oldScore); // 10
// console.log(roundScore); // outside its scope

Unlike Python if blocks, JavaScript blocks create a scope for let and const. var is hoisted and initialized to undefined; let and const cannot be accessed before their declaration is initialized (the temporal dead zone). const requires an initializer and prevents reassignment, not mutation of an object it refers to. We will practice that distinction with arrays and objects.

Worked example: follow the values

Read this as a separate small program. Predict its output before opening the explanation.

const startingLives = 3;
let lives = startingLives;
lives -= 1;
{
  const startingLives = 10;
  lives += 1;
  console.log(startingLives, lives);
}
console.log(startingLives, lives);
Reveal the output and walkthrough
10 3
3 3
  1. lives is a separate numeric binding; changing it does not change startingLives.
  2. The inner const shadows the outer name only within its block.
  3. The assignment to lives finds the outer let and changes it back to 3.
