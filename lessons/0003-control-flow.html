03 / Game rules / About 10 minutes

Skip, stop, or return

Your win: process a sequence of game events and stop at exactly the right point.

This follows the function refresher. You already use if branches; now combine them with iteration. TypeScript uses JavaScript control-flow syntax, with type checking layered on top. TypeScript control-flow analysis.

Trace one loop

const rolls = [2, -1, 4, 6, 3];
let total = 0;

for (const roll of rolls) {
  if (roll < 0) continue;
  if (roll === 6) break;
  total += roll;
}
console.log(total);

for...of gives each value. continue skips the rest of the current iteration; break leaves this loop. A return would leave the entire containing function. This is close to Python's loop behavior. MDN: loops and iteration.

What is printed?

Now leave the whole function

function describeRoll(roll: number): string {
  switch (roll) {
    case 6:
      return "bonus";
    case 1:
      return "miss";
    default:
      return "ordinary";
  }
}

A switch matches cases by strict equality. Here every branch returns, so break is unnecessary. If a branch only performed an action, it would normally need break to prevent fallthrough. MDN: switch.

Your turn: count valid guesses

Create exercises/0003-control-flow.ts. Assume finite integer inputs and a secret between 1 and 10. Write this function yourself:

function countUntilCorrect(guesses: number[], secret: number): number {
  // Your implementation.
}
  1. Use for...of to read guesses.
  2. Ignore values outside 1 through 10 with continue.
  3. Count each valid guess, including the correct one.
  4. Stop at the first correct guess. Return the count, even if none was correct.

Predict these before running:

console.log(countUntilCorrect([0, 3, 7, 9], 7)); // 2
console.log(countUntilCorrect([3, 9], 7));       // 2
console.log(countUntilCorrect([], 7));           // 0
console.log(countUntilCorrect([7, 3], 7));        // 1
tsc --noEmit --strict exercises/0003-control-flow.ts
bun run exercises/0003-control-flow.ts
Hint

Start a counter at zero. Validate before counting; count before checking for a match. Either break and return afterward, or return early on a match.
