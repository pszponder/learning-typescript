Skip, stop, or return

Your win: process a sequence of game events and stop at exactly the right point.

This follows the function refresher. You already use if branches; now combine them with iteration. TypeScript uses JavaScript control-flow syntax, with type checking layered on top. TypeScript control-flow analysis.

Worked example: follow the values

Read this as a separate small program. Predict its output before opening the explanation.

function totalBeforeStop(values: number[]): number {
  let total = 0;
  for (const value of values) {
    if (value < 0) continue;
    if (value === 0) break;
    total += value;
  }
  return total;
}
console.log(totalBeforeStop([3, -2, 4, 0, 9]));
Reveal the output and walkthrough
7
  1. 3 contributes, while -2 reaches continue and contributes nothing.
  2. 4 raises the total to 7. Zero reaches break before addition.
  3. The 9 is never visited; execution continues after the loop and returns 7.

Trace one loop

const rolls = [2, -1, 4, 6, 3];
let total = 0;

for (const roll of rolls) {
  if (roll < 0) continue;
  if (roll === 6) break;
  total += roll;
}
console.log(total);

for...of gives each value. continue skips the rest of the current iteration; break leaves this loop. A return would leave the entire containing function. This is close to Python's loop behavior. MDN: loops and iteration.

Other loop forms

for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}

let attempts = 0;
while (attempts < 2) {
  attempts++;
}

do {
  attempts++;
} while (attempts < 2); // body runs at least once

Use a counter-based for when the index matters, while when repetition depends on a changing condition, and do...while when the body must run once before checking. Ensure each loop can terminate. Prefer for...of for array values; for...in iterates property keys, including inherited enumerable ones. MDN loop guide.
