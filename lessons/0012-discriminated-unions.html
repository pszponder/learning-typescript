Model distinct game states

Your win: Make each game state carry exactly its relevant data.

A discriminated union combines object shapes with a shared literal-valued tag. Checking that tag narrows which fields exist. This avoids a single object with many optional fields that permits incoherent combinations.

// Check the discriminant before reading fields specific to a union member.
type Game =
  | { status: "waiting" }
  | { status: "playing"; turn: string }
  | { status: "finished"; winner: string };
function describe(game: Game): string {
  switch (game.status) {
    case "waiting": return "Waiting";
    case "playing": return "Turn: " + game.turn;
    case "finished": return "Winner: " + game.winner;
    default: {
      const unreachable: never = game;
      return unreachable;
    }
  }
}
console.log(describe({ status: "playing", turn: "Ada" }));

never in the default branch checks exhaustiveness: adding a new variant without handling it produces a diagnostic there. This models valid typed code, not trustworthy external data; validate incoming values before calling domain functions. A success/failure result can use the same pattern with an ok tag.

What allows safe access to a variant-specific field?

Worked example: follow the values

Read this as a separate small program. Predict its output before opening the explanation.

// Check the discriminant before reading fields specific to a union member.
type Connection =
  | { status: "offline" }
  | { status: "online"; player: string };
function connectionLabel(value: Connection): string {
  if (value.status === "offline") return "Offline";
  return "Online: " + value.player;
}
console.log(connectionLabel({ status: "offline" }));
console.log(connectionLabel({ status: "online", player: "Ada" }));
Reveal the output and walkthrough
Offline
Online: Ada
  1. The offline variant has no player field.
  2. The guard returns for offline, so the remaining value is known to be online.
  3. The tag check supplies the evidence required to read player without an assertion.
