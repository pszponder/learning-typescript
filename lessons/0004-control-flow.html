Choose the right branch

Your win: express a game decision with if, else if, else, and a ternary.

Worked example: follow the values

Read this as a separate small program. Predict its output before opening the explanation.

function ticket(age: number): string {
  if (age < 0) return "invalid";
  if (age < 12) return "child";
  return "adult";
}
console.log(ticket(-1), ticket(11), ticket(12));
Reveal the output and walkthrough
invalid child adult
  1. The guard removes negative ages before any pricing decision.
  2. Only values still in the function can reach the second condition.
  3. The boundary is less than 12, so exactly 12 takes the final return.

Follow the first matching branch

function describeLives(lives: number): string {
  if (lives < 0) {
    return "invalid";
  } else if (lives === 0) {
    return "finished";
  } else {
    return "playing";
  }
}

An if/else-if/else chain selects the first matching branch. Independent if statements can all execute unless an earlier return exits the function. A guard is an early branch that returns before the normal path. Control-flow guide.

Choose a value with a ternary

function nextTurn(lives: number): string {
  if (lives > 0) {
    return "again";
  } else {
    return "finished";
  }
}

function nextTurnCompact(lives: number): string {
  return lives > 0 ? "again" : "finished";
}

A ternary is an expression: condition ? whenTrue : whenFalse. Only the selected branch is evaluated. Python writes whenTrue if condition else whenFalse. Use it for a simple value choice; keep if branches when they are easier to read. Conditional operator.

Switch on distinct values

function describeCommand(command: string): string {
  switch (command) {
    case "start": return "playing";
    case "quit": return "finished";
    default: return "unknown";
  }
}

Switch uses strict equality. Return exits the function; otherwise use break when you need to prevent falling into the next case. Be precise with truthiness: zero and empty strings are falsy, while empty arrays and objects are truthy. Switch and conditionals.
