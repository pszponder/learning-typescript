Destructuring: unpack named and positional values

Your win: Extract just the parts of a game request that you need.

Destructuring binds variables from a value. Array patterns select by position; object patterns select by property name. Python unpacking usually requires a matching length unless a starred target is present; JavaScript can ignore extra entries and supplies undefined for missing entries.

// Destructuring creates local bindings; defaults apply to undefined values.
const cell: readonly [number, number] = [1, 2];
const [row, column] = cell;
const request = { player: "Ada", guess: 7, attempts: [3, 7] };
const { player: playerName, guess = 1, ...rest } = request;
console.log(row, column, playerName, guess, rest);

player: playerName renames a binding; it is not a type annotation. Add a type after the entire pattern if needed. Defaults apply to undefined, not null. Rest collects remaining elements or properties and must come last. Destructuring nested values does not deep-copy them. Spread expands existing values when constructing an array or object; it also makes only a shallow copy.

// Destructuring creates local bindings; defaults apply to undefined values.
const original = { score: 1, profile: { name: "Ada" } };
const copy = { ...original, score: 2 };
copy.profile.name = "Lin";
console.log(original.score, original.profile.name); // 1, Lin

// Destructuring creates local bindings; defaults apply to undefined values.
const request = { player: "Ada", bonus: 0, region: "eu" };
const { player: playerName, bonus = 5, ...rest } = request;
const [first, , third] = [2, 4, 6];
console.log(playerName, bonus, rest.region);
console.log(first, third);
Reveal the output and walkthrough
Ada 0 eu
2 6
  1. player: playerName selects the player property and creates a differently named binding.
  2. The default does not replace zero; it is used only for undefined.
  3. The empty slot skips the second array element; rest collects properties not already extracted.
