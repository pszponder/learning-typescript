# Mission: Return to professional backend development with TypeScript

## Why
Return to professional backend development with confident, practical TypeScript skills. Build on substantial current Python experience as a data engineer, using classic games as motivating projects.

## Success looks like
- Independently implement and test game rules in strict TypeScript.
- Model application state and outcomes, validate external input, and handle asynchronous work.
- Build a game backend with an API, persistence, error handling, and tests; explain the design choices.

## Constraints
- Previous JavaScript/TypeScript experience is rusty after several years.
- Use short exercises with feedback and spaced retrieval; calibrate difficulty from actual attempts.
- Use Python comparisons where helpful without assuming familiarity with Python typing tools.

## Out of scope
- No permanent exclusions established yet. Start with game logic; revisit graphics when useful to the mission.
