TypeScript / Desk reference 02

Ternaries & function forms

type Turn = "again" | "finished";

// Function declaration
function nextTurn(lives: number): Turn {
  return lives > 0 ? "again" : "finished";
}

// Function expression assigned to a const
const nextTurnExpression = function (lives: number): Turn {
  return lives > 0 ? "again" : "finished";
};

// Arrow function with a block body
const nextTurnArrow = (lives: number): Turn => {
  return lives > 0 ? "again" : "finished";
};

// Arrow function with an expression body (implicit return)
const nextTurnShort = (lives: number): Turn =>
  lives > 0 ? "again" : "finished";

A ternary chooses a value: condition ? whenTrue : whenFalse. Python writes whenTrue if condition else whenFalse. Conditional operator.

Expression bodies return implicitly; block bodies need return to return a value. Arrows capture surrounding this. Initialize a const function before calling it. Arrow function reference.

A separate function type uses an arrow for the return type:

type TurnRule = (lives: number) => Turn;
const next: TurnRule = (lives) => lives > 0 ? "again" : "finished";

The alias supplies parameter and return types. Handbook: function type expressions.
