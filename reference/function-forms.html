Function forms

Syntax for declarations, function expressions, arrows, and function types.

function addLife(lives: number): number { return lives + 1; }
const expression = function (lives: number): number { return lives + 1; };
const block = (lives: number): number => { return lives + 1; };
const concise = (lives: number): number => lives + 1;

type LifeRule = (lives: number) => number;
const rule: LifeRule = (lives) => lives + 1;

A function type describes a value; an arrow expression creates one. Const prevents rebinding. Expression bodies return implicitly; blocks need return to return a value. A const function must be initialized before calling it. Arrows capture surrounding this. Arrow reference · Function types.
