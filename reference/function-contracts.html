Function contracts

type Turn = "again" | "finished";

function nextTurn(lives: number): Turn {
  if (lives > 0) {
    return "again";
  }
  return "finished";
}

A parameter annotation follows its name. A return annotation follows the parameter list. A literal union limits a value to listed alternatives. Handbook: literal types.

Type annotations disappear at runtime. They do not validate incoming JSON. Handbook: erased types.
