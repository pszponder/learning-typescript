Variables and core collections

The four core collections are arrays, objects, Map, and Set. Tuples and Record are TypeScript descriptions of arrays and objects; destructuring is syntax.

Binding means a name referring to a value. Mutation changes an existing object; reassignment changes a binding. A shallow copy creates an outer object while retaining nested references. A tuple is a positional array type. These terms apply throughout the new lessons.

Nested collections

  • 2D arrays: board[row][column], independent rows, ragged shapes, nested iteration, and row-level copies.
  • Nested objects and dictionaries: named paths, arrays of objects, missing parents, and copying the modified path.
  • Nested Maps and Map-of-Set: initialize child containers, update/remove entries, and decide whether empty parents remain.

Each lookup adds another possible missing-value boundary. A shallow copy preserves child references. Readonly must be applied at each intended level: readonly number[][] restricts the outer array, whereas ReadonlyArray<ReadonlyArray<number>> also restricts writes through the row references. Neither freezes values at runtime.
