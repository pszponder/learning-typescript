Control-flow map

ConstructPurposeRemember
if / elseChoose branches using conditions.Use === for equality without coercion; a guard can return early.
condition ? a : bChoose one value.Only the selected expression is evaluated.
switchChoose a case by strict equality.Cases fall through unless you break, return, or throw.
for...ofIterate values of an iterable.Closest to Python for value in values.
for...inIterate enumerable string property keys.Can include inherited keys; avoid it for array values.
for (let i = 0; i < n; i++)Repeat with an explicit counter.Use when the index itself matters.
while / do...whileRepeat while a condition holds.do...while executes its body at least once.
continue / break / returnSkip an iteration / leave a loop / leave a function.A break inside switch exits that switch, not an enclosing loop.
throw / try / catch / finallyRaise, handle, and clean up after exceptions.Do not return from finally: it can override an earlier result or error.
&& / || / ??Short-circuit evaluation.|| defaults on any falsy value; ?? defaults only on null or undefined.
async / awaitCoordinate promise-based work.await inside for...of is sequential; forEach does not await async callbacks.

JavaScript falsy values include false, 0, -0, 0n, empty string, null, undefined, and NaN. Empty arrays and objects are truthy. Use explicit checks when 0 is meaningful. Control flow and errors · Loops and iteration.

const lives = 0;
console.log(lives || 3); // 3
console.log(lives ?? 3); // 0

Async reading for later: async functions and forEach limitations. A catch around an awaited operation can handle its rejection; a detached promise needs its own error handling.
